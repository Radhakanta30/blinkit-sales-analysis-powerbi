# 🛒 BlinkIT Sales Dashboard

An interactive Power BI dashboard built to analyze BlinkIT grocery sales performance, customer ratings, outlet characteristics, and product trends.

## 📊 Project Overview

This dashboard provides insights into:

* Total Sales Performance
* Average Sales per Product
* Customer Ratings Analysis
* Item Category Distribution
* Outlet Size Analysis
* Outlet Location Analysis
* Outlet Establishment Trends
* Fat Content Analysis
* Sales by Outlet Type

The goal of this project is to transform raw grocery sales data into actionable business insights using Power BI.
