# BlinkIT Sales Analysis – Power BI

![BlinkIT Sales Dashboard](<Screenshot 2026-09-27 231132.png>)

## 📊 Project Overview

This project is an interactive Power BI dashboard developed to analyze BlinkIT sales performance and outlet-level business metrics.

The dashboard provides a visual overview of sales, average sales, item count, customer ratings, outlet establishment trends, outlet size, outlet location, item types, and fat-content distribution.

The goal of this project is to transform sales data into an interactive dashboard that makes it easier to understand business performance and identify important trends.

---

## 🎯 Objectives

- Analyze overall sales performance.
- Track key performance indicators (KPIs).
- Understand sales trends across outlet establishment years.
- Compare performance across different outlet sizes and locations.
- Analyze item types and fat-content categories.
- Provide interactive filters for business analysis.
- Present data in a simple and visually understandable format.

## 📈 Dashboard Features

### 1. Sales Analysis

The dashboard provides an overview of total sales and average sales, helping to understand the overall sales performance.

### 2. Outlet Establishment Analysis

The outlet establishment chart shows sales trends across different establishment years.

### 3. Outlet Size Analysis

The dashboard provides a visual breakdown of sales based on outlet size.

### 4. Outlet Location Analysis

Sales performance can be analyzed according to different outlet location types.

### 5. Item Type Analysis

The dashboard allows analysis of sales across different item categories.

### 6. Fat Content Analysis

The dashboard compares sales based on fat-content categories such as Regular and Low Fat.

### 7. Interactive Filters

Users can interact with the dashboard using filters such as:

- Outlet Location Type
- Outlet Size
- Item Type
